# PHARMA+
Landing page pharmacie/parapharmacie.

## Utilisation
1. Garder index.html, style.css et app.js dans le même dossier.
2. Ouvrir index.html dans Chrome/Edge/Firefox.
3. Une connexion internet est nécessaire pour les polices Google et les images de démonstration.

## À remplacer pour la production
- produits/prix dans app.js
- images et assets
- coordonnées de la pharmacie
- système de commande/paiement
- upload ordonnance vers un backend sécurisé
- règles de délivrance selon le pays
